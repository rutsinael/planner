**Описание проекта**

Итоговая работа по курсу Основы Go. Планировщик задач. Задачи можно добавлять с описанием, 
датой выполнения, а так же выставлять правила повторения. 
Rest API
SQL Lite

**Список выполненных заданий со звёздочкой**
Кроме обязательных задач реализованы все правила повторения задач и создан образ для docker.

**Инструкция по запуску кода локально**
docker build .
docker run -d -p 7540:7540 <image id>

**Инструкция по запуску тестов**
go test ./tests
